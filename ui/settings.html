Model connection

The key is stored locally in dubai-estate/.ai.env (gitignored) and sent only from the local proxy to the model endpoint — never exposed in the page. DeepSeek is the default; you can point at any OpenAI-compatible endpoint.
Checking proxy…
DeepSeek key? Create one at platform.deepseek.com → API Keys. The official model is deepseek-chat (latest V3.x). Click ↻ Load models after entering your key to see every model this account can use (e.g. deepseek-reasoner), or just type any model id.

No DeepSeek key yet? Use the “Local cli-proxy-api” preset — it works instantly with your running proxy (key sk-local-proxy-key-2024).

Advanced

The proxy must be running for these settings to take effect. Run the “Start AI Proxy (DeepSeek assistant)” VS Code task, or from dubai-estate/:
python3 tools/ai_proxy.py
Saved settings are persisted to .ai.env and applied live (no restart). Env vars set at startup take precedence until the first save via this page.
